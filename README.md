# 💜 Loki (لوكي) - رفيقك ومساعدك النفسي الدافئ

> **"صاحبك اللي في ضهرك دايماً.. بيفضفض معاك، يطبطب على قلبك، ويحببك في الحياة."**

تطبيق **Loki** هو مساعد نفسي وشخصي مبني بأحدث التقنيات وأفضل واجهات المستخدم الحديثة، مصمم خصيصاً ليكون مستمعاً حنوناً وودوداً باللهجة المصرية والعربية اللطيفة بدون أي تنظير أو أحكام، مع دعم التفاعل النصي والصوتي البشري عالي الدقة، واقتراح ردود ذكية لتسهيل الحديث.

---

## ✨ المميزات الرئيسية

1. **ذكاء عاطفي ونفسي دافئ (Empathetic AI Persona)**:
   - يتحدث باللهجة المصرية الحنونة والمريحة ("يا غالي"، "أنا سامعك وحاسس بيك"، "حقك عليا تزعل"، "ولا تشيل هم كل مر هيمر").
   - يدعم محرك **Google Gemini Flash** (مجاني وسريع) بالإضافة إلى **محرك لوكي الذكي المدمج** الذي يعمل حتى بدون مفتاح API.

2. **صوت بشري طبيعي جداً (Microsoft Edge Neural TTS)**:
   - أصوات استوديو فائقة الواقعية مجانية 100% وبدون أي حدود أو تكلفة.
   - خيارات للأصوات: **سلمى (Salma)** بصوت نسائي هادئ وحنون، أو **شاكر (Shakir)** كصوت أخ وصديق مقرب.
   - تشغيل تلقائي للردود صوتياً مع تحكم كامل (كتم/تشغيل وزر "اسمعني" لكل رسالة).

3. **إملاء وإدخال صوتي من المايكروفون (Speech-to-Text)**:
   - إمكانية التحدث للوكي مباشرة بصوتك بلهجتك الطبيعية ليقوم بتحويلها لنص وإرسالها.

4. **اقتراحات ردود سريعة ذكية (Suggested Reply Chips)**:
   - بعد كل رسالة من لوكي، يقترح عليك 3 خيارات سريعة ولطيفة يمكنك الضغط عليها لتكمل الفضفضة فوراً دون عناء الكتابة.

5. **تمرين التنفس الهادئ (Breathing & Grounding Exercise)**:
   - تمرين تنفس تفاعلي (شهيق - كتم - زفير) مهدئ لنبضات القلب والتوتر مع مؤقت مرئي ناعم.

6. **مقياس الحالة المزاجية (Mood Selector)**:
   - اختيار حالتك النفسية الحالية (مبسوط، رايق، مضغوط، زعلان، طاقتك مخلصة) ليتكيف لوكي مع مشاعرك بدقة.

7. **جرعة أمل يومية (Daily Hope Sparks + Confetti)**:
   - بطاقة متجددة بعبارات أمل وتفاؤل واقعية مع تفاعل احتفالي مبهج.

8. **تصميم زجاجي عصري وفاخر (Modern Glassmorphic Dark UI)**:
   - ألوان مريحة للعين (Dark Slate + Purple & Pink Gradients)، أيقونات حديثة وخطوط عربية راقية (Alexandria).

## 🚀 طريقة التشغيل السريعة

### 1. المتطلبات:
- **Node.js** (إصدار 18 فما فوق).

### 2. التثبيت (تم التثبيت مسبقاً):
في المجلد الرئيسي للمشروع:
```bash
npm install
cd server && npm install
cd ../client && npm install
```

### 3. تشغيل التطبيق (الخادم والواجهة معاً بأمر واحد):
في المجلد الرئيسي `d:\LOKI`:
```bash
npm run dev
```

- **رابط التطبيق (الواجهة)**: [http://localhost:3000](http://localhost:3000)
- **رابط الخادم (الـ Backend)**: [http://localhost:5000](http://localhost:5000)

## 🔑 مفتاح Google Gemini API المجاني (اختياري)

- التطبيق يعمل فوراً بدون مفتاح بفضل محرك لوكي الاحتوائي المدمج.
- للحصول على ذكاء غير محدود ومحادثة ممتدة بأعلى قدرة تحليلية، يمكنك الحصول على مفتاح **Gemini API مجاني 100%** في 30 ثانية:
  1. ادخل على: [Google AI Studio](https://aistudio.google.com/app/apikey).
  2. اضغط **Create API key**.
  3. افتح تطبيق لوكي واضغط على أيقونة **الإعدادات ⚙️** في الأعلى والصق المفتاح هناك، أو ضعه داخل ملف `server/.env`:
     ```env
     GEMINI_API_KEY=AIzaSy...
     PORT=5000
     ```
